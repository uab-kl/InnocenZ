Wiring the agency roster page (`apps/web/src/routes/agency/roster.tsx`, ~1067 lines, `/agency/roster?view=planning`) to the backend, per a 3-phase plan. The whole backend chain already exists: `/api/v1/pr`, `/shift`, `/shift-assignment`, `/payment-voucher` + the weekly PV generation job. See [[pv-auto-generated-weekly]].

**Model mapping:** one roster slot = one `shift_assignment` (+ its `shift` + `pr`). A slot's `id` IS the assignment id, so by-id actions map 1:1.
