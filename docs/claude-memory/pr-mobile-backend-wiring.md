**Standing Database Rules (user repeats every message — always honor):**
1. Reuse existing tables — never create a new one when one fits.
2. If a table has audit cols, `created_at/updated_at/created_by/updated_by` must all be present together.
3. Use FK joins to pull data from other tables (e.g. outlet/pr name) — never duplicate a name column.
