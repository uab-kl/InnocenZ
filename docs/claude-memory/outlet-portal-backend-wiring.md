**⚠️ CRITICAL RBAC RE-CHECK (2026-07-19, during Special Service wiring) — a table existing ≠ the ROUTE accepting an outlet token.** Read every `*.routes.ts` guard. Findings:
- `/shift`, `/shift-assignment`, `/pr` (pr-personnel) = **`router.use(requireRole('admin','agency'))`** → **OUTLET GETS 403. NOT wireable from the outlet token.** This BLOCKS outlet **History**, **Home-hub live shifts**, and **Post-Job SHIFT create** — the outlet literally cannot read/write shifts or PR names via the backend. Would need a backend change to add outlet-scoped shift read routes (NOT the outlet feature → coworker's domain → leave demo).
- `/special-service`, `/outlet`, `/commission`(GET), `/outlet-transaction`, `/member-subscription`, `/subscription`(GET), `/admin-request`(POST only) = **no blanket role guard → outlet-accessible** (writes mostly `requireAdmin`). These are the genuinely wireable set.
